# Manual test checklist (user launches Minecraft)

Use a separate Fabric **1.21.1** instance with README's exact dependencies. Preserve your real profile. Start with only this stack; additional rendering mods are a later compatibility test.

1. **Single page:** launch with the default pack and shaders disabled, then enabled. Check terrain, UI, block items and particles. Confirm versions and no unexpected physical paging/errors in `latest.log`.
2. **Force paging:** run `python tools/generate_test_pack.py` once. Enable `build/test-packs/poa-synthetic-1.21.1.zip` and add JVM arguments `-Dpagesofatlas.development=true -Dpagesofatlas.devPageSize=2048` to the test instance only. Default synthetic sprites are 1024 square; logs must report at least 3 physical block-atlas pages. This setting is off by default and is never enabled by the mod itself.
3. Place stone, dirt, cobblestone, bricks, sand, gravel, gold block, diamond block, glass, oak leaves, redstone block and prismarine. Check all faces, mip levels at distance, cutout holes, translucent glass ordering, mining particles, held/dropped/inventory items, and prismarine's 2-frame animation. Distinct colors make wrong-page sampling visible. Check paintings with your normal painting pack; the synthetic pack does not force the painting atlas to split.
4. **Materials:** with a LabPBR shader, enable normal/specular effects and POM if supported. Check synthetic height ramps, alternating rough/smooth squares and metallic/nonmetallic blocks on every page. Shaders off / diffuse-only appearance does not pass this step. Record shader name, version and settings. An unsupported-sampler or texture-unit error means that shader needs an adapter or fewer sampler demands; do not report it as a passed backport test.
5. **Reload:** F3+T repeatedly, toggle shaders, switch from synthetic to vanilla and back, and leave/re-enter the world. Look for stale colors, missing material pages, GL errors, frozen animation or growing GPU memory. Any crash needs the full log.
6. Remove both development JVM arguments and the synthetic pack. Test your private **Patrix 128x** stack, then **256x** separately. Check Continuity CTM seams, custom models, normals/height, specular, animation and item/particle rendering on both. Keep paid assets local.
7. Only after those pass, add other mods individually. DH, Physics Mod and Dynamic Trees rendering has not been validated. Report exact versions and the first combination that fails.

Return the JAR checksum, full mod list, GPU/driver, page-count lines, shader name/settings, `latest.log`/crash report and focused screenshots. Do not upload paid pack or private shader archives. Offline build/tests are already handled by the project; this checklist supplies the missing runtime evidence.
