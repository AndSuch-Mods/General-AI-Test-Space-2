# US Pipe Cooling Tower Quote Walkdown

Mobile-friendly field questionnaire for the **US Pipe Bessemer Air Compressor Cooling Tower** redundancy quote.

## Live site

https://andsuch-mods.github.io/General-AI-Test-Space-2/

## Purpose

Use the page during the site walkthrough to:

- Work through scope-specific questions by category.
- Type answers and notes directly under each question.
- Mark questions **Skip / known / N/A**.
- Filter to open, critical, answered, or skipped questions.
- Track photos and measurements needed for the quote.
- Add custom questions while onsite.
- Copy or export a Markdown summary after the walkthrough.

## Data storage

Answers are saved in the browser's `localStorage` on the device being used. There is no server-side database and no walkthrough data is committed back to GitHub.

## Source scope

Built around the supplied **Air Compressor Cooling Tower Project Scope** for US Pipe's Bessemer Pipe Plant, including the dual motor/VFD redundancy, clutch system, RTDs, zero-speed feedback, PLC/network integration, electrical work, commissioning, and quote requirements.
